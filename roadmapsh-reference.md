# Roadmap.sh reference notes — 2026-08-24

Roadmap.sh describes itself as a community effort offering roadmaps, guides, projects, resources, and journeys to help developers choose a path and grow in their careers. Its main structure combines role-based roadmaps, skill-based roadmaps, project ideas, best practices, and guides.

Useful structural references for Hana:

- Official home: https://roadmap.sh/
- Roadmap index: https://roadmap.sh/roadmaps
- Beginner guidance: https://roadmap.sh/get-started
- Computer Science roadmap: https://roadmap.sh/computer-science
- AI Engineer roadmap: https://roadmap.sh/ai-engineer
- Cyber Security roadmap: https://roadmap.sh/cyber-security
- Backend roadmap: https://roadmap.sh/backend
- Android roadmap: https://roadmap.sh/android

The official pages show role-based paths such as Frontend, Backend, DevOps, Android, AI Engineer, Data, Machine Learning, Cyber Security, UX Design, and Network Engineer. They also show skill paths such as Python, Computer Science, SQL, Linux, Git and GitHub, APIs, AI Agents, and Data Structures & Algorithms.

The beginner page emphasizes choosing a clear goal, building projects, learning to get unstuck, and using a relevant roadmap rather than following an unrelated generic path. It also presents AI-powered guidance that analyzes experience and suggests relevant roadmaps.

Hana should take the structural idea—foundations → core skills → projects → proof → career direction—without copying Roadmap.sh content. Hana’s version must remain adaptive to the student’s chosen goal, existing knowledge, university context, available study time, and completed evidence. The UI should show the current step first and keep deeper explanation, prerequisites, resources, practice, mastery, and project details behind an expandable control.
