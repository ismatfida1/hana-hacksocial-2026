# Separate Hana prototype validation notes

The isolated prototype runs at http://localhost:3001/ and does not modify the published Hana project. The mobile viewport shows a minimal first screen with HANA branding, a clear greeting, one expressive robot image, Today’s Mission, duration, reason, and one Start action. The Start action immediately changes to “Mission in progress,” reveals one small task, and changes Hana’s expression to thinking. Secondary actions are limited to Ask Hana and Save progress. The supplied robot artwork is reused as visual inspiration through the existing Hana asset, while the layout and treatment are original. Desktop build, TypeScript, production build, and tests also passed before browser validation.
The corrected prototype now opens on a greeting-only screen with Hana and a single “Let’s begin” action. After that action, the second screen shows Today’s Mission with Hana, mission title, duration, reason, Start, Ask Hana, and Choose career. Career selection is intentionally the next screen reached through the visible Choose career action, matching the corrected page-order direction and keeping each screen focused.
The Home-only redesign now matches the requested visual hierarchy in the browser: Hana is the primary visual focus, the greeting is short, Today’s Mission is the only main card with Python Functions, 25 min, one reason line, Start, and a small four-step progress indicator. The bottom navigation contains only Home, Journey, Projects, Opportunities, and Ask Hana. No roadmap, career choices, project list, statistics, chatbot, or explanatory feature wall appears in the Home content.
The public preview now matches the attached specification for the first two screens. Screen 1 contains only HANA branding, Good morning greeting, Hi, I’m Hana, How’s your day going?, Hana’s illustration with an expressive face, and one I’m ready button. Screen 2 contains only the career question, a short helper sentence, Software Engineering, AI / Machine Learning, Cybersecurity, Cloud / DevOps, Data Science / Data Engineering, Mobile Development, Other, and I don’t know yet — Help me find my path. No mission, roadmap, projects, statistics, or chatbot appears on Screen 2.
The adaptive prototype now opens with the approved greeting-only Screen 1. After “I’m ready,” Screen 2 asks “What do you want to learn?” and shows Programming, AI / Machine Learning, Web Development, App Development, Cybersecurity, Data Science, Game Development, Computer Science Fundamentals, Cloud / DevOps, Robotics, UI/UX, and Something else / I don’t know yet. The fixed Python mission is no longer used for onboarding.
The public adaptive preview now preserves the greeting-only opening and then asks “What do you want to learn?” before any journey is generated. It offers broad study areas across programming, AI, web, apps, cybersecurity, data, games, computer science, cloud, robotics, and UI/UX, plus Something else / I don’t know yet. This removes the fixed Python-first assumption from onboarding.
The adaptive flow was tested through Cybersecurity. After selecting Cybersecurity, Hana asks the student’s current level and then their goal before building the journey. This confirms the flow does not jump directly from a fixed subject to a Python mission; the chosen subject and learner context are collected first.
The undecided-student test reached the path-finder entry after the greeting and study-area screens. Choosing “✨ Something else / I don’t know yet” opens Hana’s own-words prompt with a text field and a separate “Help me find my path instead” action. This is the intended branch for students who do not want to choose a predefined study area.
