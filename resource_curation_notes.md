# Hana resource curation notes — 2026-08-24

## Decision
Hana will not show the full lists of AI tools, YouTube channels, or programming libraries on the main screen. The user asked for only necessary links. Roadmap cards show one best resource, with direct lesson pages preferred over homepages or large directories.

## Selected user-provided resource
The Cisco course is represented by the official Cisco Networking Academy page rather than the third-party aggregator URL:

- Cisco Introduction to Cybersecurity: https://www.netacad.com/courses/introduction-to-cybersecurity

The official search result describes it as a beginner course with a free start, approximately six hours, and hands-on labs. The third-party scholarship page was not used as the canonical resource because course claims and availability should be checked on Cisco’s own site.

## Why most submitted lists are not placed directly in the roadmap
The AI tools list contains general productivity services, several of which duplicate capabilities Hana already provides or require separate accounts, paid plans, or sensitive uploads. They may be considered later as optional tools, but they are not necessary for a beginner roadmap.

The programming, Python, SEO, and online-business lists mostly point to channel homepages rather than specific lessons. Showing dozens of channels would create choice overload and would not meet Hana’s one-best-resource rule. The attached CS Career Blueprint is used as a curriculum direction: prerequisites, demonstrated mastery, projects, GitHub, open source, internships, and shipped work. Its themes are represented in the detailed journey model, not copied as a giant document page.

## Existing compact resources retained
- Python fundamentals: Python official tutorial
- Web fundamentals and APIs: MDN direct learning pages
- AI evaluation: Google Machine Learning Crash Course
- Responsible AI: Google AI principles
- Cybersecurity: Cisco Networking Academy, then OWASP
- Cloud/DevOps: Docker, GitHub Actions, Google SRE Workbook
- Data: pandas, Matplotlib, Khan Academy statistics, Data to Viz
- UI/UX: Nielsen Norman Group and Material Design

## Link checks
The selected external links were checked with HTTP requests where the host allows them. Some legitimate sites reject HEAD requests (for example, Material Design) or block automated requests (for example, Cisco); those are not treated as broken solely because of that response. The official URLs are preserved for browser verification by the student.

## Safety and trust wording
Hana must not promise income, certificates, deadlines, eligibility, job placement, or guaranteed results. Opportunity pages must point to official sources and ask the student to check the current details before applying.
